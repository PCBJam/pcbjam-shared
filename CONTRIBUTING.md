# Contributing to @pcbjam/shared

Thanks for your interest. This package is part of
[PCBJam](https://github.com/PCBJam/pcbjam), and we don't accept pull requests or
code from outside the team; we write all the code ourselves. You can still help:

- **Found a bug?** Open an [issue](https://github.com/PCBJam/pcbjam-shared/issues)
  here, or post it in the `#bug-reports` forum on our
  [Discord](https://discord.gg/ybhqJxjR3E), with the steps to reproduce it.
- **Have an idea or feedback?** Open an issue, or post it in `#feedback` on the
  same Discord.
- **Found a security problem?** Don't post it in an issue, on Discord or
  anywhere else public. Use
  **Report a vulnerability** under this repo's **Security** tab, or email
  [hello@pcbjam.com](mailto:hello@pcbjam.com).
